# Log Analyzer

Десктопний застосунок (Python + PyQt5) для аналізу текстових лог-файлів: пошук підозрілих записів за регулярними виразами, статистика за категоріями та її візуалізація у вигляді діаграми.

## Можливості

- Вибір лог-файлу через діалог або перетягуванням (drag & drop)
- Пошук за категоріями Error / Denied / Failed / Warning (регулярні вирази)
- Фоновий аналіз великих файлів без зависання інтерфейсу (QThread + прогрес-бар)
- Таблиця результатів: сортування, фільтри за категорією, копіювання рядка
- Стовпчикова діаграма статистики (без сторонніх бібліотек, QPainter)
- Збереження звіту у JSON або TXT

## Встановлення

```bash
python -m venv venv
venv\Scripts\activate        # Windows

pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

Для тесту можна обрати `data/sample.log, data/big_sample.log, data/huge.sample.log`.

## Структура проєкту

```
log-analyzer/
├── main.py
├── models/         # LogEntry, LogAnalyzer
├── storage/        # збереження звітів (JSON/TXT)
├── ui/             # вікна, стилі, віджети
├── scripts/        # генератор тестових лог-файлів
└── data/           # приклади лог-файлів
```

## Стек

Python 3, PyQt5
